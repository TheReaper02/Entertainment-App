# Entertainment Web App

A media browsing app inspired by streaming platforms, built as part of a Frontend Mentor advanced challenge.

## Features

- Browse movies and TV series with per-page search
- Bookmark content that persists across sessions
- Simulated auth flow — login and signup with full form validation
- Protected routes that redirect unauthenticated users

## Technical Highlights

- React Context API with `useReducer` for global bookmark state
- `AuthContext` with localStorage persistence for simulated authentication
- React Router v7 nested routes with a shared Layout and protected navigation
- Mobile-first responsive design across mobile, tablet, desktop and ultra-wide
- Unit tested with Vitest and React Testing Library — covering form validation, user interactions and component behaviour

## Stack

React 19 · Tailwind CSS v4 · React Router v7 · Vitest · React Testing Library
